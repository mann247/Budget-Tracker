This app helps you track income and expenses and see your budget for the month in real time.

Add Income
1. In the income section, enter a Description in the input field.
2. Enter the Amount
3. Click Add Income
4. The Total Income and Total Budget will update, and the entry will appear in the table.


Add Expense
1. In the Expense section, enter a Description (e.g. "Groceries", "Gas")
2. Choose a Category from the dropdown (e.g., Food,Transportation, Housing, etc.)
3. Enter the amount (positive number, e.g. $34.99)
4. Click Add Expense
5. The Total Expense and Total Budget will update and the entry appears in the table (category shows by its readable name).

Budget Summary
- Total Income : Sum of all income entries
- Total Expenses : Sum of all expense entries
- Total Budget for the Month: The Total Income - The Total Expenses
**These values will updates automatically as you input information**

Transaction History Table
- Each row shows: Description, Category(For Expense), Amount, and Type (Income/Expense)
- Use The ❌ button to remove a row from the table.

Clearing the Tracker for next month
- Click *Clear All* to remove all entries and reset totals to zero

Validation and Errors
- Descriptions can't be empty
- Amounts must be valid positive numbers
- If the user puts in valid inputs, you'll see an alert and the entry won't be added.
